# NETFLIX AZƏRBAYCAN

Responsive Azerbaijani cinema discovery experience. The catalog includes 34 distinct local SVG illustrations made for this project; they are labeled as illustrations and are not official posters or movie stills. Eleven full films link to the official Azərbaycanfilm YouTube channel and use YouTube's embedded player with a direct official viewing fallback. Other catalog entries do not display an unsupported watch action.

## Run locally

```bash
npm install
npm run dev
```

## Validate / deploy

```bash
npm run typecheck
npm run build
```

Deploy by importing this repository into Vercel and selecting the Next.js preset. No secrets or external API keys are required. User list and recently opened titles are stored only in browser localStorage.

## Catalog provenance

- [Azerbaijanfilm official feature-film catalog](https://azerbaijanfilm.az/kinofilmler/)
- [Azerbaijan.az cinema history, 1935–1988](https://azerbaijan.az/en/related-information/164)
- [Kinobox catalog](https://kinobox.az/en/browse)

Descriptions are brief editorial summaries written for this interface; they are not quoted synopses. Rights and playback availability have not been inferred from a title's presence in a catalog. Since no blanket reuse license for the archival stills/posters was verified, no copyrighted film imagery is bundled.
